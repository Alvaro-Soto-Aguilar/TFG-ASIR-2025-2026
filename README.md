## 📖 Resumen del proyecto
<p align="justify">
El proyecto consiste en implementar una infraestructura de red y elaborar una plataforma web segura conectada a una base de datos en la nube para una clínica de especialidades médicas denominada Clínica Brossi, S.L.
</p>

<p align="justify">
Implementar la estructura de red de la clínica Brossi, S.L. es fundamental para el buen funcionamiento de la misma, ya que permite que todos los equipos,  dispositivos informáticos y componentes estén conectados entre ellos y que funcionen correctamente. También es importante para que los datos estén seguros protegiéndonos de posibles ataques o accesos indebidos.
</p>

<p align="justify">
Por otra parte, el diseño de una plataforma web permite que los pacientes puedan acceder para pedir, consultar, modificar y anular citas, chatear con un asistente virtual o consultar resultados e informes. Esto permite agilidad y resuelve el problema de esperas en llamadas telefónicas, pérdida de tiempo y desplazamientos innecesarios.
</p>

<p align="justify">
Este proyecto permite que la clínica tenga todos los datos perfectamente almacenados y ordenados con total seguridad, que se pueda acceder a los mismos de manera fácil y rápida y que haya total privacidad de los datos personales y de salud de los pacientes ya que se delimitan los diferentes accesos que tiene el personal de la clínica y los pacientes, evitando riesgos de seguridad y permitiendo a los pacientes una navegación fácil, cómoda e intuitiva a través de la página web. Además, para reforzar la seguridad, se exige doble autenticación para consultar informes y modificar datos personales, entre otros. Asimismo, es necesario el uso de la nube ya que los pacientes (y los usuarios autorizados) acceden a la página web desde fuera de la clínica.
</p>

<p align="justify">
En el sitio web se han implementado una serie de mejoras con respecto a otras páginas web de la competencia.
</p>

## 🧱 Metodología
<p align="justify">
Para la realización de este proyecto  se ha utilizado una metodología incremental que consiste en hacer el proyecto por partes, diviéndolo en pequeños módulos más pequeños de manera que cada una de estas partes incorporan funciones adicionales sobre la parte anterior, permitiendo revisar los avances, modificar los posibles errores y entregar los resultados de forma progresiva.
</p>
